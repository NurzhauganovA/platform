# platform-api

Каркас платформы и модули подключённых проектов.

Каркас берёт на себя то, что одинаково для любого проекта: вход и права,
очередь задач с прогрессом и учётом стоимости, хранилище файлов с раскладкой
по содержимому. Предметная логика остаётся в проектах — модуль здесь только
переводит её на язык HTTP.

```
src/platform_api/
├── app.py            сборка приложения из реестра модулей
├── auth/             вход, сессии, роли
├── jobs/             очередь, прогресс, исполнитель
├── storage/          файлы по sha256
└── modules/
    ├── __init__.py   контракт подключения проекта
    ├── table.py      колонки книги Excel → таблица в браузере, права
    ├── skstore/      закупы Самрук-Қазына
    ├── omarket/      предзаказы OMarket.kz
    └── tender/       разбор тендерной документации
```

Читать начинать с `modules/__init__.py`: там описано, что проект сообщает о
себе платформе. Дальше — `modules/<slug>/core.py`, единственное место, где
модуль обращается к своему ядру.

Разработка и запуск описаны в корневом `README.md` и `CLAUDE.md`.
